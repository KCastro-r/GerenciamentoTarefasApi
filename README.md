# Sistema de Gerenciamento de Tarefas

## 📌 Nossa Tarefa (O Projeto)
Este projeto é um sistema de gerenciamento de tarefas com cadastro de usuário. A aplicação foi desenvolvida para permitir que uma usuária se cadastre, acesse o sistema e gerencie suas próprias tarefas, tendo a capacidade de criar, visualizar, editar e excluir itens de sua lista. O back-end em .NET foi integrado a um front-end em Angular.
